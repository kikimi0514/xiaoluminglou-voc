# 曉鹿鳴樓 VOC 顧客真實心聲輿情分析系統 (Voice of Customer Analysis Dashboard)

本專案為針對知名江浙菜館「曉鹿鳴樓」之 320 則 Google Maps 真實顧客評論進行深度文字探勘、情緒分析與商業洞察的互動式輿情分析網站。

## 🌟 核心成果摘要

* **分析樣本**：320 則真實顧客評論（覆蓋度 100%）
* **總體評價結構**：正面好評 55.3% ｜ 中立平淡 29.1% ｜ 強烈負評 15.6%
* **核心品牌診斷**：「菜色實力硬核，毀在翻桌心急」

### 🏆 三大最佳評價（三大亮點）
1. **「銷魂東坡肉」正統江浙風味，老饕外賓折服**（89次高頻提及，好評率 83.1%）
2. **「峭壁石斛燉雞湯」甘甜清爽與「細心去籽銀耳紅棗羹」**（峰終定律體驗極佳）
3. **高性價比大份量（人均千元吃超飽）、捷運停車雙便利與多功能包廂歡唱**

### ⚠️ 三大最差評價（三大痛點）
1. **「趕場式」翻桌催客與奪命連環詢問打包**（筷子未動先催收盤，負評破壞率 100%）
2. **外場態度傲慢臉臭，接待高層「盛氣凌人擺官威」**（21則強烈投訴）
3. **重口味大菜吃完才上菜飯、缺料擅自替代與破萬年菜大翻車**

## 🚀 部署與線上瀏覽

本專案採用純靜態架構（Tailwind CSS + 原生 JavaScript），無須任何後端依賴，可直接透過 **GitHub Pages** 一鍵發布。

### 線上展示 (GitHub Pages)
啟用 GitHub Pages 後，網址格式為：
`https://<你的 GitHub 帳號>.github.io/<儲存庫名稱>/`

### 本地預覽
直接在瀏覽器中開啟 `index.html` 或 `曉鹿鳴樓_VOC_互動儀表板.html` 即可完整體驗所有互動功能。

---

## 🛠️ 功能特點
* **320 則評論即時檢索庫**：支援關鍵字搜尋、情緒過濾、標籤快速切換。
* **招牌菜色評價透視矩陣**：東坡肉、石斛雞湯、菜飯、鯽魚等讚賞點與雷區預警。
* **專家落地營運處方**：針對痛點提供翻桌政策、主管接待、出菜時序等 4 大具體 SOP 建議。
